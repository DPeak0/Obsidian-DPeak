# 变量、别名例题一

1. 将 `/bin/true` 文件拷贝到 `/opt/command` 目录下，并且允许此目录下的命令文件可以像执行 ls 命令那样执行
```bash
[root@dpeak ~]# cp /bin/true /opt/command/
[root@dpeak ~]# PATH=$PATH:/opt/command/

```

2. 永久定义变量，让系统上所有用户的变量 `name_user` 的值为 `rocky_user`。要求 devops 用户使用的变量 `name_user` 的值为 `devops`，要求 zhangsan 用户使用的变量 `name_user` 的值为 `zhangsan`
```bash
[root@dpeak ~]# echo "export name_user=rocky_user" >> /etc/bashrc
[root@dpeak ~]# echo $name_user
rocky_user

[root@dpeak ~]# echo "export name_user=devops" >> /home/devops/.bashrc
[root@dpeak ~]# su - devops
[devops@dpeak ~]$ echo $name_user
devops

[root@dpeak ~]# echo "export name_user=zhangsan" >> /home/zhangshan/.bashrc
[root@dpeak ~]# su - zhangshan
[zhangshan@dpeak ~]$ echo $name_user
zhangsan

```

3. 为 devops 用户定义一个永久别名 `lsuser`，执行 `lsuser` 将会以长格式的方式列出 devops 用户家目录下的所有文件
```bash
[root@dpeak ~]# echo "alias lsuser='ls -la ~devops'" >> /home/devops/.bashrc
[root@dpeak ~]# su - devops
[devops@dpeak ~]$ lsuser

drwx------.  2 devops root   6 Aug 24 16:45 .cache
drwxr-xr-x.  4 devops root  39 Aug 24 15:26 .mozilla

```

4. 为所有用户定义一个永久别名 `cppasswd`，执行 `cppasswd` 将会把 `/etc/passwd` 文件拷贝到 `/tmp` 目录下，并且以 `passwd-年-月-日-时-分秒` 格式保存
```bash
[root@dpeak ~]# echo "alias cppasswd='cp /etc/passwd /tmp/passwd-\$(date +%F-%T)'" >> /etc/bashrc
[root@dpeak ~]# bash
[root@dpeak ~]# cppasswd
[root@dpeak ~]# ls -ld /tmp/passwd-2026-09-01-16\:52\:16
-rw-r--r--. 1 root root 3471 Sep  1 16:52 /tmp/passwd-2026-09-01-16:52:16

```

# sed 流编辑案例：请你说出以下 sed 命令的作用

sed -n '/dns/Ip' /root/passwd
```text
将/root/passwd文件中的dns关键词忽略大小写打印输出到屏幕，不输出模式空间的内容
```
sed -i.bak 's/root/redhat/' /root/passwd
```text
先备份源文件/root/passwd,然后将/root/passwd文件中的每一行第一个匹配到的关键词root替换为redhat
```
sed '4,9d' /root/passwd
```text
删除/root/passwd文件中的第4到第9行，将剩下的内容打印输出到屏幕
```
sed 's\$/sbin/nologin\$/bin/bash$' /root/passwd
```text
将/root/passwd文件中的每一行匹配到的第一个关键词/sbin/nologin替换为/bin/bash
```
sed '1a\Hello Sed' /root/passwd
```text
将/root/passwd文件中的第1行的下一行新增内容Hello Sed
```
sed '\\\$/bin/bash$d' /root/passwd
```text
将/root/passwd文件中包含关键词/bin/bash的行删除，将剩余内容打印输出到屏幕
```
sed  -i.bak  '1s/root/huawei/g' /root/passwd
```text
先备份源文件/root/passwd,然后将/root/passwd文件中的第一行中所有包含关键字root替换为huawei
```
sed '/^#Port 22/i\NiHao Sed' /root/sshd_config
```text
在文件/root/sshd_config中以#Port 22开头的上一行新增内容NiHao Sed
```
