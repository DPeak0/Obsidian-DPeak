KVM虚拟化要求：
1. 创建一台RockyLinux8系统的KVM虚拟机，名字为demo1，采用virt-manager方式安装
2. 创建一台RockyLinux8系统的KVM虚拟机，名字为demo2，采用virt-install方式安装
3. 准备一台PXE服务端，配置PXE相关服务，能够给其他主机安装系统
    在KVM虚拟机所在的宿主机上，配置桥接网络br0，要求新创建的pxe-client KVM虚拟机可以通过PXE服务端自动化安装操作系统
## 配置桥接网络
```bash
[root@dpeak ~]# nmcli connection delete ens160 
Connection 'ens160' (f2ed3493-4b6f-4bc0-8d92-6dce41dc5dd8) successfully deleted.
[root@dpeak ~]# nmcli connection add type bridge ifname br0 con-name br0
Connection 'br0' (eee98124-0f61-4b8d-a3ff-cf7972786c92) successfully added.
[root@dpeak ~]# nmcli connection add type bridge-slave  ifname ens160 con-name ens160 master br0 
Connection 'ens160' (7daeb901-74f1-47fc-9d3c-b4442b6477b3) successfully added.

[root@dpeak ~]# nmcli connection modify br0 ipv4.method manual ipv4.addresses 192.168.200.128/24 ipv4.gateway 192.168.200.2 ipv4.dns 223.5.5.5 autoconnect yes 
[root@dpeak ~]# nmcli connection up br0 
Connection successfully activated (master waiting for slaves) (D-Bus active path: /org/freedesktop/NetworkManager/ActiveConnection/11)

```
## 安装虚拟化套件
- 安装虚拟化套件
```bash
[root@dpeak ~]# yum groupinstall -y 'Virtualization Host'
```
- 启动libvirtd服务
```bash
[root@dpeak ~]# systemctl restart libvirtd
```

## 通过图形化工具安装KVM虚拟机
- 安装图形化工具
```bash
[root@dpeak ~]# yum install -y virt-manager
```
- 运行图形化工具
```bash
[root@dpeak ~]# virt-manager
```
