KVM虚拟化要求：
1. 创建一台RockyLinux8系统的KVM虚拟机，名字为demo1，采用virt-manager方式安装
2. 创建一台RockyLinux8系统的KVM虚拟机，名字为demo2，采用virt-install方式安装
3. 准备一台PXE服务端，配置PXE相关服务，能够给其他主机安装系统
    在KVM虚拟机所在的宿主机上，配置桥接网络br0，要求新创建的pxe-client KVM虚拟机可以通过PXE服务端自动化安装操作系统
## 配置桥接网络
```bash
[root@dpeak ~]# nmcli connection delete ens160 
Connection 'ens160' (f2ed3493-4b6f-4bc0-8d92-6dce41dc5dd8) successfully deleted.
[root@dpeak ~]# nmcli connection add type bridge ifname br0 con-name br0
Connection 'br0' (eee98124-0f61-4b8d-a3ff-cf7972786c92) successfully added.
[root@dpeak ~]# nmcli connection add type bridge-slave  ifname ens160 con-name ens160 master br0 
Connection 'ens160' (7daeb901-74f1-47fc-9d3c-b4442b6477b3) successfully added.

[root@dpeak ~]# nmcli connection modify br0 ipv4.method manual ipv4.addresses 192.168.200.128/24 ipv4.gateway 192.168.200.2 ipv4.dns 223.5.5.5 autoconnect yes 
[root@dpeak ~]# nmcli connection up br0 
Connection successfully activated (master waiting for slaves) (D-Bus active path: /org/freedesktop/NetworkManager/ActiveConnection/11)

```

## 通过命令行工具安装KVM虚拟机
- 安装virt-install命令行工具
```bash
[root@dpeak ~]# yum install -y virt-install
```
- 
```bash
[root@dpeak images]# cd /var/lib/libvirt/images/
[root@dpeak images]# qemu-img create -f qcow2 -o preallocation=metadata demo2.qcow2 20G
```

```bash
[root@dpeak images]# virt-install --name demo2 --vcpus 1 --memory 1024 --network bridge=br0,model=virtio --disk path=/var/lib/libvirt/images/demo2.qcow2 --location /var/lib/libvirt/images/Rocky-8.4-x86_64-dvd1.iso --graphics spice,listen=127.0.0.1  --noautoconsole

```

## PXE
### 安装所需软件包
```bash
[root@dpeak ~]# yum install -y httpd tftp-server dhcp-server syslinux-nonlinux
```

```bash
[root@dpeak ~]# cat /usr/share/doc/dhcp-server/dhcpd.conf.example > /etc/dhcp/dhcpd.conf
[root@dpeak ~]# vim /etc/dhcp/dhcpd.conf
# A slightly different configuration for an internal subnet.
subnet 192.168.200.0 netmask 255.255.255.0 {
  range 192.168.200.100 192.168.200.110;
  option domain-name-servers 223.5.5.5;
  option domain-name "internal.example.org";
  option routers 192.168.200.2;
  option broadcast-address 192.168.200.255;
  default-lease-time 600;
  max-lease-time 7200;
  next-server 192.168.200.129;
  filename "pxelinux.0";
}

```
