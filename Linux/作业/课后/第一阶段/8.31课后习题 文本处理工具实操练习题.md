- 使用 `cat` 命令查看 `/etc/passwd` 文件，并显示所有隐藏符号。
```bash
[root@dpeak ~]# cat -A /etc/passwd
```

- 使用 `head` 和 `tail` 命令组合，查看 `/etc/passwd` 文件的第 5 行到第 10 行的内容。
```bash
[root@dpeak ~]# head -n 10 /etc/passwd | tail -n +5
```

- 在 `/var/log/syslog` 文件中，使用 `grep` 查找包含关键字 "error" 的行，要求忽略大小写、显示行号并高亮匹配内容。
```bash
[root@dpeak ~]# grep --color=auto -in error /var/log/syslog
```

- 使用 `grep` 在 `/etc/passwd` 文件中过滤出以 "root" 开头的行。
```bash
[root@dpeak ~]# grep ^root /etc/passwd
root:x:0:0:root:/root:/bin/bash
```

- 使用 `cut` 命令，以冒号 `:` 为分隔符，提取 `/etc/passwd` 文件中第 1 列（用户名）和第 7 列（登录 Shell）
```bash
[root@dpeak ~]# cut -d : -f 1,7 /etc/passwd
```

- 将 `/etc/passwd` 文件的内容根据UID的大小进行降序排序，UID最大的数所在的行显示在第一行。
```bash
[root@dpeak ~]# sort -t : -k 3 -rn /etc/passwd
```

 - 使用 `tr` 命令将字符串 "hello world" 中的所有小写字母转换为大写字母。
```bash
[root@dpeak ~]# echo "Hello world"| tr 'a-z' 'A-Z'
HELLO WORLD
```

- 使用 `tr` 命令删除字符串 "abc123def456" 中的所有数字字符。
```bash
[root@dpeak ~]# echo abc123def456 | tr -d '1-9'
abcdef
```

- 使用 `vimdiff` 命令比较 `/etc/passwd` 和 `/etc/shadow` 两个文件的差异。
   ```bash
   [root@dpeak ~]# vimdiff /etc/passwd /etc/shadow
   ```

- 使用 `wc` 命令统计 `/etc/passwd` 文件的行数、单词数和字节数。
```bash
[root@dpeak ~]# wc /etc/passwd
65  128 3422 /etc/passwd
```

- 使用 `grep` 命令在 `/etc` 目录下递归搜索所有文件中包含 "localhost" 的行（根据内容localhost搜索文件名）。
```bash
[root@dpeak ~]# grep -r localhost /etc/
```

- 使用 `cat` 命令将 `/etc/hostname` 和 `/etc/hosts` 两个文件的内容合并输出，并显示行号。
```bash
[root@dpeak ~]# cat -n /etc/hostname /etc/hosts
 1  dpeak
 2  127.0.0.1   localhost localhost.localdomain localhost4 localhost4.localdomain4
 3  ::1         localhost localhost.localdomain localhost6 localhost6.localdomain6
```
- 使用 `grep` 命令配合扩展正则，在 `/etc/passwd` 文件中查找包含 "bash" 或 "sh" 的行。
```bash
[root@dpeak ~]# grep -E 'bash|sh' /etc/passwd
```
- 使用 `head` 命令查看 `/etc/passwd` 文件的前 3 行内容，然后通过管道传给 `cut` 命令，只提取第 1 列。
```bash
[root@dpeak ~]# head -n 3 /etc/passwd | cut -d : -f 1
root
bin
daemon
```
-  使用 `tail` 命令实时查看 `/var/log/syslog` 文件的追加情况（模拟日志监控场景）。
```bash
[root@dpeak ~]# tail -f /var/log/syslog
```
