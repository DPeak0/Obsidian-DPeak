 

# 8.25 系统管理综合实操

## 任务清单

### 第一部分：用户与组管理

1. **创建服务用户** 创建一个名为 `webapp` 的系统用户，用于运行未来的 Web 服务。要求：
   - 指定其 UID 为 `3003`
   - 指定其家目录为 `/srv/webapp`
   - 设置其不允许登录系统
2. **创建普通用户** 创建一个名为 `devuser` 的普通用户，用于开发人员登录。要求：
   - 添加描述信息 "Web Developer"
3. **验证用户信息**
   - 使用 `id` 命令查看 `webapp` 用户的 UID信息
   - 查看 `/etc/passwd` 文件的最后两行，确认 `webapp` 和 `devuser` 用户是否已成功添加，并观察其 Shell 字段的区别

---

```bash
[root@dpeak ~]# useradd -r -u 3003 -md /srv/webapp -s /sbin/nologin  webapp

[root@dpeak ~]# useradd -c "Web Developer" devuser

[root@dpeak ~]# id webapp
uid=3003(webapp) gid=974(webapp) groups=974(webapp)
```

### 第二部分：文件系统与目录操作

1. **创建项目目录结构** 以递归方式创建以下完整的项目目录结构：

   ```
   /srv/webapp/project/conf
/srv/webapp/project/logs
   /srv/webapp/project/static
/srv/webapp/project/uploads
   ```

2. **路径切换**

   - 从任意位置，使用**绝对路径**切换到 `/srv/webapp/project` 目录
   - 使用**相对路径**进入 `conf` 目录
   - 使用一个命令返回到 `project` 目录
   - 再使用一个命令直接切换到 `devuser` 用户的家目录

3. **文件查找与查看**

   - 使用 `ls` 命令，以人类可读的方式（如 K、M，自动换算大小单位）列出 `/srv/webapp/project` 下所有子目录的详细信息
   - 使用 `ls` 命令，列出 `/srv/webapp` 目录本身（而不是其内容）的详细权限信息

------

```bash
[root@dpeak ~]# mkdir -p /srv/webapp/project/{conf,logs,static,uploads}
[root@dpeak ~]# ls /srv/webapp/project/
conf  logs  static  uploads


[root@dpeak ~]# cd /srv/webapp/project/
[root@dpeak project]# cd conf/
[root@dpeak conf]# pwd
/srv/webapp/project/conf
[root@dpeak conf]# cd ..
[root@dpeak project]# pwd
/srv/webapp/project
[root@dpeak project]# cd ~devuser/
[root@dpeak devuser]# pwd
/home/devuser
```

### 第三部分：文件管理操作

1. **文件创建与部署**
   - 在 `devuser` 的家目录下，创建一个名为 `nginx.conf` 的空文件
   - 将系统的 `/etc/passwd` 文件复制一份到 `/srv/webapp/project/conf/` 目录下，并重命名为 `app_users.conf`
   - 再次复制 `/etc/passwd` 文件到 `/srv/webapp/project/conf/` 目录下，这次**保留其所有原始属性**（权限、时间戳等），并重命名为 `app_users.conf.bak`
2. **文件移动与重命名**
   - 将 `devuser` 家目录下的 `nginx.conf` 文件移动到 `/srv/webapp/project/conf/` 目录中
   - 进入 `/srv/webapp/project/conf/` 目录，将 `app_users.conf.bak` 文件重命名为 `app_users.conf.backup`
3. **文件删除**
   - 强制删除 `/srv/webapp/project/conf/` 目录下的 `app_users.conf` 文件，不给予任何提示

------

```bash
[root@dpeak devuser]# touch nginx.conf
[root@dpeak devuser]# cp /etc/passwd /srv/webapp/project/conf/app_users.conf
[root@dpeak devuser]# ls /srv/webapp/project/conf/
app_users.conf
[root@dpeak devuser]# cp -a /etc/passwd /srv/webapp/project/conf/app_users.conf.bak
[root@dpeak devuser]# ll /etc/passwd
-rw-r--r--. 1 root root 2734 Aug 25 18:17 /etc/passwd
[root@dpeak devuser]# ll /srv/webapp/project/conf/app_users.conf.bak
-rw-r--r--. 1 root root 2734 Aug 25 18:17 /srv/webapp/project/conf/app_users.conf.bak

[root@dpeak devuser]# mv /home/devuser/nginx.conf /srv/webapp/project/conf/
[root@dpeak devuser]# ls /srv/webapp/project/conf/
app_users.conf  app_users.conf.bak  nginx.conf
[root@dpeak devuser]# cd /srv/webapp/project/conf/
[root@dpeak conf]# mv app_users.conf.bak app_users.conf.backup
[root@dpeak conf]# ls
app_users.conf  app_users.conf.backup  nginx.conf

[root@dpeak conf]# rm -rf /srv/webapp/project/conf/app_users.conf
[root@dpeak conf]# ls
app_users.conf.backup  nginx.conf
```
