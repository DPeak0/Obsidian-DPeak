# 配置本地 YUM 仓库实战案例
准备工作：把系统自带的所有的 repo 文件先移走
需求：配置本地 YUM 仓库
- 仓库配置文件名为rocky.repo
- 第一个仓库名BaseOS，描述信息baseos，仓库地址为/mnt/cdrom/BaseOS，开启软件包校验，公钥文件位置在/etc/pki/rpm-gpg/目录下
- 第二个仓库名AppStream，描述信息appstream，仓库地址为/mnt/cdrom/BaseOS，开启软件包校验，公钥文件位置在/etc/pki/rpm-gpg/目录下
  ```bash
[root@dpeak yum.repos.d]# vim /etc/yum.repos.d/iso.repo

[BaseOS]
name=baseos
baseurl=file:///mnt/cdrom/BaseOS
gpgcheck=1
gpgkey=file:///etc/pki/rpm-gpg/RPM-GPG-KEY-rockyofficial

[AppStream]
name=appstream
baseurl=file:///mnt/cdrom/AppStream
gpgcheck=1
gpgkey=file:///etc/pki/rpm-gpg/RPM-GPG-KEY-rockyofficial

  ```
- 最后测试使用 yum clean all 清理缓存，以及执行 yum makecache 建立缓存验证是否配置成功
  ```bash
  [root@dpeak yum.repos.d]# yum clean all
13 files removed
[root@dpeak yum.repos.d]# yum makecache
baseos                                                      249 MB/s | 2.5 MB     00:00
appstream                                                   272 MB/s | 7.1 MB     00:00
Metadata cache created.

  ```
