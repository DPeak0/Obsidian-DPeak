# DNS主从
## DNS服务端配置
### 安装软件包
```bash
[root@dpeak ~]# yum install -y bind

```
### 修改配置文件
#### 修改bind配置文件
```bash
[root@dpeak ~]# vim /etc/named.conf
options {
        listen-on port 53 { any; };  #修改为any表示允许所有人访问
        listen-on-v6 port 53 { ::1; };
        directory       "/var/named";
        dump-file       "/var/named/data/cache_dump.db";
        statistics-file "/var/named/data/named_stats.txt";
        memstatistics-file "/var/named/data/named_mem_stats.txt";
        secroots-file   "/var/named/data/named.secroots";
        recursing-file  "/var/named/data/named.recursing";
        allow-query     { any; };   #修改为any表示允许所有人向本机查询

```
#### 修改区域配置文件
```bash
[root@dpeak ~]# vim /etc/named.rfc1912.zones
zone "dpeak.cn" IN {
        type master;
        file "dpeak.cn";
        allow-update { none; };
};

zone "200.168.192.in-addr.arpa" IN {
        type master;
        file "200.168.192.in-addr.arpa";
        allow-update { none; };
};

```
#### 修改DNS记录文件
##### 正向解析配置文件
```bash
[root@dpeak ~]# cd /var/named/
[root@dpeak named]# ls
data  dynamic  named.ca  named.empty  named.localhost  named.loopback  slaves
[root@dpeak named]# cp -a named.localhost dpeak.cn
[root@dpeak named]# vim dpeak.cn
$TTL 1D
@       IN SOA  dns.dpeak.cn. admin.dpeak.cn. (
                                        0       ; serial
                                        1D      ; refresh
                                        1H      ; retry
                                        1W      ; expire
                                        3H )    ; minimum
        NS      dns.dpeak.cn.
        A       127.0.0.1
        AAAA    ::1
dns     A       192.168.200.128
www     A       192.168.200.128
```
##### 反向解析配置文件
```bash
[root@dpeak named]# cp -a named.loopback 200.168.192.in-addr.arpa
[root@dpeak named]# vim 200.168.192.in-addr.arpa
[root@dpeak named]# cat 200.168.192.in-addr.arpa
$TTL 1D
@       IN SOA  dns.dpeak.cn. admin.dpeak.cn. (
                                        0       ; serial
                                        1D      ; refresh
                                        1H      ; retry
                                        1W      ; expire
                                        3H )    ; minimum
        NS      dns.dpeak.cn.
        A       127.0.0.1
        AAAA    ::1
128     PTR     www.dpeak.cn.

```

### 关闭防火墙和SELinux
```bash
[root@dpeak named]# systemctl stop firewalld.service
[root@dpeak named]# setenforce 0

```
