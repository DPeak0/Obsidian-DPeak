# 8.27 课中 ACL权限案例:


在系统上创建一个acl-user用户，并且设置密码为1

1. 允许acl-user用户在/opt目录下创建文件和列出文件以及进入目录的权限，其他用户没有这个创建文件的权限

   ```bash
   
   [root@dpeak ~]# useradd demo-user
   
   [root@dpeak ~]# passwd demo-user
   Changing password for user demo-user.
   New password:
   BAD PASSWORD: The password is a palindrome
   Retype new password:
   passwd: all authentication tokens updated successfully.
   
   [root@dpeak ~]# setfacl -m u:acl-user:rwx /opt
   
   ```

   

2. 给/opt目录赋予acl-user用户组的acl权限，让组的成员对于/opt目录拥有完全控制权限

   ```bash
   [root@dpeak ~]# setfacl -m g:acl-user:rwx /opt/
   ```

   

3. 新建用户demo-user，将demo-user加入到acl-user用户组中，尝试使用demo-user用户在/opt目录下创建文件
    demo.file，并且说明为什么demo-user用户可以在/opt目录下新创建文件

  ```bash
  [root@dpeak ~]# gpasswd -a demo-user acl-user
  Adding user demo-user to group acl-user
  [root@dpeak ~]# su - demo-user
  [demo-user@dpeak ~]$ touch /opt/demo.file
  [demo-user@dpeak ~]$ ls -l /opt/demo.file
  -rw-rw-r--. 1 demo-user demo-user 0 Aug 27 10:21 /opt/demo.file
  
  ```

  

  4.给demo-user用户配置sudo提权，允许demo-user用户提权到所有用户身份执行所有的命··令，并且不需要密码验证

  ```bash
  
  [root@dpeak ~]# vim /etc/sudoers
  demo-user       ALL=(ALL)       NOPASSWD:ALL
  
  ```

  5.通过demo-user用户使用sudo命令提权到root用户身份创建/opt/dir目录，并且将其目录文件的拥有组修改为acl-user

  ```bash
  [demo-user@dpeak ~]$ sudo mkdir /opt/dir
  [demo-user@dpeak ~]$ ls -ld /opt/dir
  drwxr-xr-x. 2 root root 6 Aug 27 10:25 /opt/dir
  [demo-user@dpeak ~]$ sudo chgrp acl-user /opt/dir
  [demo-user@dpeak ~]$ ls -ld /opt/dir
  drwxr-xr-x. 2 root acl-user 6 Aug 27 10:25 /opt/dir
  
  ```

  6.清空/opt目录的所有acl权限

```bash
[root@dpeak ~]# setfacl -b /opt/

[root@dpeak ~]# getfacl /opt/
getfacl: Removing leading '/' from absolute path names
# file: opt/
# owner: root
# group: root
user::rwx
group::r-x
other::r-x

```
