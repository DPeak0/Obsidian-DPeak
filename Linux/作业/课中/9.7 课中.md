at计划任务例题：
1. 要求在指定的时间 7月18号，执行激活ens160网卡的命令
   ```bash
	[root@dpeak ~]# at '17:10 2029-7-15'
	warning: commands will be executed using /bin/sh
	at> nmcli connection up  ens160
	at> <EOT>
	job 3 at Sun Jul 15 17:10:00 2029

   ```
2. 要求在指定的时间12月29号，删除/tmp /opt /root目录下所有的文件
   ```bash
	[root@dpeak ~]# echo rm /tmp/ /opt/ /root/ > at
	[root@dpeak ~]# at '17:00 2026-12-29' < at 
	warning: commands will be executed using /bin/sh
	job 5 at Tue Dec 29 17:00:00 2026

   ```
3. 仅允许root用户和devops用户使用at任务，其他用户全部拒绝掉
```bash
[root@dpeak ~]# vim /etc/at.allow
[root@dpeak ~]# cat /etc/at.allow 
root
devops
```
crontab计划任务例题：
1. 要求以devops用户身份，在每个月的11号，下午3点开始，每隔20分钟执行，rm -rf ~/\*，通过crontab -e方式去创建计划任务
	```bash
	[root@dpeak ~]# crontab -u devops -e
	no crontab for devops - using an empty one
	crontab: installing new crontab
	[root@dpeak ~]# crontab -l -u devops 
	*/20 15 11 * * rm -rf ~/*
	```
2. 要求以root用户身份，每个小时的10分执行rm -rf /tmp/\*，以及执行cp -a /etc/ /root，要求通过编辑/etc/crontab文件实现
	```bash
	[root@dpeak ~]# vim /etc/crontab
	10 * * * * root rm -rf /tmp/* 
	10 * * * * root cp -a /etc/ /root/
	
	```
