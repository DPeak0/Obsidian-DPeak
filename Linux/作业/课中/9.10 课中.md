# 打包压缩案例题
准备2台主机
1.A主机上将/etc目录和/root目录进行打包,并且使用gzip工具压缩。压缩的文件名/opt/etc-root.tar.gz
```bash
[root@DPeak-A ~]# tar -cf /opt/etc-root.tar /etc/ /root/
tar: Removing leading `/' from member names
tar: Removing leading `/' from hard link targets
[root@DPeak-A ~]# gzip /opt/etc-root.tar
[root@DPeak-A ~]# ls -l /opt/etc-root.tar.gz
-rw-r--r-- 1 root root 8391844 Sep 10 11:24 /opt/etc-root.tar.gz

```
2.将A主机刚刚打包压缩的文件传输给B主机的/root目录下,并且B主机需将其解压缩和解包
```bash
[root@DPeak-A ~]# rsync -v /opt/etc-root.tar.gz root@192.168.200.200:/root
etc-root.tar.gz

sent 8,393,982 bytes  received 35 bytes  1,865,337.11 bytes/sec
total size is 8,391,844  speedup is 1.00

[root@DPeak-B ~]# ls -l etc-root.tar.gz
-rw-r--r--. 1 root root 8391844 Sep 10 11:27 etc-root.tar.gz

```
3.在B主机上下载https://nginx.org/download/nginx-1.20.2.tar.gz、https://www.kernel.org/pub/linux/kernel/v7.x/linux-7.1.12.tar.xz并且将其解压缩放到/tmp目录下
```bash
[root@DPeak-B ~]# wget  https://nginx.org/download/nginx-1.20.2.tar.gz https://www.kernel.org/pub/linux/kernel/v7.x/linux-7.1.12.tar.xz

[root@DPeak-B ~]# tar -xf nginx-1.20.2.tar.gz -C /tmp
[root@DPeak-B ~]# tar -xf linux-7.1.12.tar.xz -C /tmp

```
