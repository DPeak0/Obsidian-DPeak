# grub.cfg引导配置文件丢失

- 模拟故障
  ```bash
  [root@dpeak ~]# rm -f /boot/grub2/grub.cfg
  
  #重启
  [root@dpeak ~]# reboot
  ```
- 找到boot分区与根分区
![](https://oss.bwihz.cn/%20PicGo/20260917113424392.png)
- 指定boot分区
  ```bash
  grub> set root=(hd0.msdos2)
  ```
  ![](https://oss.bwihz.cn/%20PicGo/20260917113621233.png)
- 指定内核文件+真正的根文件系统
```bash
grub> linux /vmlinuz-4.18.0-305.3.1.e18_4.x86_64 root=/dev/sda2
```
  ![](https://oss.bwihz.cn/%20PicGo/20260917113650006.png)
- 指定initramfs文件
```bash
grub> initrd /initramfs-4.18.0-305.3.1.e18_4.x86_64.img
```
  ![](https://oss.bwihz.cn/%20PicGo/20260917113750956.png)
- 继续引导
```bash
grub> boot
```
  ![](https://oss.bwihz.cn/%20PicGo/20260917113817023.png)
- 进入系统后重新生成grub.cfg文件
```bash
[root@dpeak ~]# grub2-mkconfig -o /boot/grub2/grub.cfg
Generating grub configuration file ...
done

```
- 重启验证,可以正常引导进入系统
  ```bash
  [root@dpeak ~]# reboot

  ```
