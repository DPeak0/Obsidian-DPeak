脚本文件名:/opt/init.sh
要求如下：
执行完脚本之后，能够满足以下的要求
1./tmp目录下的所有的临时文件全部被清理
2.自动将/etc整个目录备份至/opt/目录下，并且备份后的名字为/opt/etc-backup-年-月-日
3.创建/opt/backup文件，并且权限为777
```bash
#!/bin/bash
rm -rf /tmp/*
cp -a /etc /opt/etc-backup-$(date +%F)
mkdir /opt/backup
chmod 777 /opt/backup

```

• 案例需求：
创建俩个脚本文件/opt/useradd.sh 和/opt/userdel.sh
执行useradd.sh脚本的时候，传入的第一个参数作为创建的用户名
传入的第二个参数作为这个用户的密码存在的
/opt/useradd.sh zhangsan1 redhat 表示创建 zhangsan1 用户，并且密码设置为 redhat
执行userdel.sh脚本的时候，传入的第一个参数作为删除的用户名
/opt/userdel.sh zhangsan1，表示删除这个用户，并且同时删除家目录和邮箱文件，同时此脚本执行完成就被删除
```bash
[root@dpeak ~]# vim /opt/useradd.sh
#!/bin/bash
useradd $1
echo $2 | passwd --stdin $1

[root@dpeak ~]# chmod a+x /opt/useradd.sh
[root@dpeak ~]# /opt/useradd.sh zhangsan1 redhat
Changing password for user zhangsan1.
passwd: all authentication tokens updated successfully.

```

```bash
[root@dpeak ~]# vim /opt/userdel.sh
#!/bin/bash
userdel -r $1
rm -rf $0

```
