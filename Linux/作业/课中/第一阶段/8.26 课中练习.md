# 8.26 课中练习
 
1. 创建user1,user2,user3 三个用户的时候满足要求如下（请你保证系统上没有提前存在这些用户）
    - user1 家目录在/data目录下，该用户的描述为testuser
    - user2 用户的uid 应当为2000
    - user3 用户应当使用 /sbin/nologin这个登录shell，并且测试是否能够登录
    
    ```bash
    [root@dpeak ~]# useradd -md /data -c testuser user1
    [root@dpeak ~]# useradd -u 2000 user2
    [root@dpeak ~]# useradd -s /sbin/nologin user3
    [root@dpeak ~]# su - user3
    This account is currently not available.
    
    ```
    
    
    
2. 创建一个用户组itgroup，gid为2500（满足以下题目要求）
    - 将user1，user2，user3批量加入到itgroup组中
    - 将user1做为itgroup组的管理员
    - 修改user3用户的UID为2026，描述信息为 RHCE_USER，家目录为/tmp/user3
    - 将user3用户添加到root组中

    ```bash
    [root@dpeak ~]# gpasswd -M user1,user2,user3 itgroup
    [root@dpeak ~]# gpasswd -A user1 itgroup
    [root@dpeak ~]# usermod -u 2026 -c RHCE_USER -md /tmp/user3 user3
    [root@dpeak ~]# gpasswd -a user3 root
    Adding user user3 to group root
```
    

    
3. 创建一个用户memeda01（满足以下题目要求）

4. 请你清理所有创建的用户和用户组（满足以下题目要求）
    - 删除所有的itgroup组中的成员，然后删除itgroup组
    - 删除用户user3、user2、user1，包括用户家目录、邮箱文件

    ```bash
    [root@dpeak ~]# groupmems -g itgroup -p
    [root@dpeak ~]# groupdel itgroup
    [root@dpeak ~]# userdel -r user1
    [root@dpeak ~]# userdel -r user2
    [root@dpeak ~]# userdel -r user3
    ```
