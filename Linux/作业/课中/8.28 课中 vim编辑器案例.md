# 8.28 课中 vim编辑器案例:
 准备工作：先复制/etc/passwd文件到/root目录下
1.使用vim打开文件，显示行号

```bash

[root@dpeak ~]# cp /etc/passwd /root/

[root@dpeak ~]# vim passwd
:set nu
```

2.删除第2行一整行内容

```bash
2G
dd
```

3.把第10行以及后面所有行都删除掉

```bash
10G
dG
```

4.快速跳转到文件的末尾行，并且在编辑模式下，在末尾行的下一行插入数据demo

```bash
G
o

 10 demo

```

5.将demo这一行内容复制1次，在最后一行粘贴5次

```bash
yy
5p
```

6.将所有的bash关键字替换为ai

```bash
:%s/bash/ai/g
```

7.不保存刚刚的操作，直接退出，重新打开文件查看内容

```bash
:q!
```
