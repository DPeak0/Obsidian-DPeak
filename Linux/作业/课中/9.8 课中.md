
- 假设现在你要修改某个软件的配置文件，但是你不知道文件的绝对路径，不过你知道文件包含ssh关键字，而且你知道这个文件是在/etc目录下；请问，通过find命令应该怎么搜索，才可以把所有包含ssh关键字的文件搜索出来
	```bash
	[root@dpeak ~]# find /etc/ -name '*ssh*'
	```
- 如果现在配置文件是cfg结尾的，怎么搜索出来系统上所有以cfg结尾的文件呢？
	```bash
	[root@dpeak ~]# find / -name '*.cfg'
	```
- 要求你搜索系统上所有以sel开头的文件，并且忽略sel关键字的大小写，要求将搜索出来的文件路径另存为到/opt/ok中，报错的信息另存为到/opt/error中
  ```bash
  [root@dpeak ~]# find / -name 'sel*' > /opt/ok 2> /opt/error
  ```
- zhangsan用户 在系统上的好多位置都生成了文件,找到这个zhangsan用户的文件
  ```bash
  [root@dpeak ~]# find / -user zhangsan
  ```

- 请你搜索出系统上所有的空文件，并且将其文件路径另存为到/opt/null.txt中
	```bash
	[root@dpeak ~]# find / -size -1k > /opt/null.txt
	```
- 请你搜索出/etc目录下大于50M的文件
	```bash
	[root@dpeak ~]# find /etc/ -size +50M
	```
- 需要你搜索系统的小文件（小文件的范畴小于64k）
  ```bash
  [root@dpeak ~]# find / -size -64k
  ```
- 请你搜索出整个系统上文件大小在5k和6k之间的文件
  ```bash
  [root@dpeak ~]# find / -size 6k
  ```


- 搜索/etc目录下最近1天之内修改过内容的文件
  ```bash
  [root@dpeak ~]# find /etc/ -mtime -1
  ```
- 查询系统上/root目录下，10分钟之内被访问过的文件
	```bash
	[root@dpeak ~]# find /root/ -amin -10
	```
- 查询系统上在35分钟之内被访问过的文件
  ```bash
  [root@dpeak ~]# find / -amin -35
  ```
- 查询3天之前被修改过的文件
  ```bash
  [root@dpeak ~]# find / -mtime +3
  ```



- 搜索文件的拥有人有完全控制权限，拥有组和其他人只有只读权限
  ```bash
  [root@dpeak ~]# find / -perm 744
  ```
- 查询系统上其他人有x权限的文件
  ```bash
  [root@dpeak ~]# find / -perm -001
  ```
- 想要搜索系统上拥有suid权限的文件
	```bash
	[root@dpeak ~]# find / -perm -4000
	```


- 搜索出系统上文件具备suid权限的，并且文件的拥有人是root用户的文件！
  ```bash
	[root@dpeak ~]# find / -user root -a -perm -4000
  ```
- 搜索出系统上文件的拥有人是root用户的，拥有组是wheel组的文件
	```bash
	[root@dpeak ~]# find / -user root -a -group wheel
	```
- 搜索出不属于任何用户的文件并且文件大小是在4M和5M之间的文件
  ```bash
  [root@dpeak ~]# find / -nouser -a -size 5
  ```
- 想要搜索devops用户的文件 或者 zhangsan用户的文件
  ```bash
  [root@dpeak ~]# find / -user devops -o -user zhangsan
  ```
- 搜索不是zhangsan用户的文件
  ```bash
	[root@dpeak ~]# find / ! -user zhangsan
  ```


- 想在/etc目录下搜索文件是root用户的目录文件
	```bash
	[root@dpeak ~]# find /etc -user root -a -type d
	```
- 要求搜索/etc目录下以.config结尾的普通文件
  ```bash
  [root@dpeak ~]# find /etc/ -type f -a -name '*.config'
  ```
- 要求搜索/etc目录下文件大于5M但是小于10M的普通文件
```bash
[root@dpeak ~]# find /etc -size +5M -a -size -10M
```
- 要求搜索属于devops用户的并且权限包含读的权限的普通文件
```bash
[root@dpeak ~]# find  / -user devops  -a -perm -400 -a -type f
```
- 要求搜索其他人包含rx权限的目录文件
  ```bash
  [root@dpeak ~]# find / -perm -005 -a -type d
  ```

- 搜索系统上包含pass关键字的文件，要忽略/proc目录的搜索
  ```bash
  [root@dpeak ~]# find / -name '*pass*' -o -path /proc -prune
  ```
