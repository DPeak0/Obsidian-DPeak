#### 网卡命名规则详解
- **传统命名方式**：`ethX`
	- **格式**：`eth0`, `eth1`, `eth2`...
	- 优点：设备命名具备规律，对于未来使用自动化工具来说很方便
	- 缺点：设备命名是根据开机时候加载的设备顺序命名

- **基于固件特征的命名方式：ens160、ens192、ens224、eno166667等
    - en：Ethernet以太网设备
    - s：支持热插拔
    - o：板载设备：网卡设备是镶嵌在主板上
    - wl：无线网卡设备
    - p：pcie插槽设备

## 修改网卡设备命名方式
### 方式一：
```Bash
#打开/etc/default/grub文件
vim /etc/default/grub
GRUB_TIMEOUT=5
GRUB_DISTRIBUTOR="$(sed 's, release .*$,,g' /etc/system-release)"
GRUB_DEFAULT=saved
GRUB_DISABLE_SUBMENU=true
GRUB_TERMINAL_OUTPUT="console"
GRUB_CMDLINE_LINUX="rhgb quiet net.ifnames=0 biosdevname=0" ###这行添加参数 net.ifnames=0 biosdevname=0
GRUB_DISABLE_RECOVERY="true"
GRUB_ENABLE_BLSCFG=true

#执行grub2-mkconfig命令
grub2-mkconfig -o /boot/grub2/grub.cfg


```
