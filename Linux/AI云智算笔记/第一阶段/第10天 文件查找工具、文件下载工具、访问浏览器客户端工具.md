### HTTP状态码说明
| 状态码   | 含义                          |
| ----- | --------------------------- |
| `200` | 访问正常                        |
| `301` | 永久跳转                        |
| `302` | 临时跳转，常见 HTTP 跳转到 HTTPS      |
| `304` | 走缓存，资源未修改                   |
| `403` | 访问被拒绝，可能是权限、SELinux、服务端主动拒绝 |
| `404` | 资源找不到，服务端没有这个文件             |
| `500` | 服务器内部错误                     |
| `502` | 网关错误                        |
| `503` | 服务不可用                       |
|       |                             |
