## ACL权限  
#### 1.ACL 是什么
- ACL：访问控制列表（Access Control List）
- 作用：在传统 `rwx` 权限基础上，实现更精细的权限控制。
- 核心能力：
    - 允许**指定用户**对文件拥有特定权限
    - 允许**指定用户组**对文件拥有特定权限
#### 2.权限匹配优先级
访问文件时，按以下顺序匹配（**先命中即生效**）：
1. 拥有人（owner）
2. 用户 ACL（指定用户）
3. 拥有组（group）
4. 用户组 ACL（指定组）
5. 其他人（other）
#### 3.查看 ACL 权限
![image.png](https://oss.bwihz.cn/PicGo/20260830005436645.png)
- 使用 `ls -l` 查看，若权限位末尾出现 `+`，表示该文件有 ACL 权限。
- 使用 [[2.Linux命令选项解析#getfacl：查看ACL权限|getfacl <文件>]] 查看详细的 ACL 权限列表。

#### 4.mask（权限掩码）

- **含义**：控制 ACL 权限的**有效权限**。
- **规则**：
    - 用户或组的实际权限 = 其 ACL 权限 **∩** mask 权限（按位与）。
	    例如：ACL 为 `rwx`，mask 为 `r--`，则有效权限为 `r--`。

- 文件有 ACL 后，`ls -l` 显示的**组权限位**实际是 **mask 值**。
- 使用 `chmod g+xxx` 或 `setfacl -m m::rwx` 可修改 mask。

#### 5.修改/删除 ACL 权限（[[2.Linux命令选项解析#setfacl：修改ACL权限|setfacl]]）
 - **为指定用户设置 ACL**
```bash
setfacl -m u:用户名:权限 文件
```
- **为指定用户组设置 ACL**
```bash
setfacl -m g:组名:权限 文件
```
- **修改文件本身的拥有组（不带用户/组名）**
```bash
setfacl -m g::权限 文件   # 注意双冒号
```
- **删除所有 ACL**：
```bash
setfacl -b 文件
```
- **删除指定用户的 ACL**：
```bash
setfacl -x u:用户名 文件
```
- **删除指定组的 ACL**：
```bash
setfacl -x g:组名 文件
```

#### 6.默认 ACL（继承）
- **用途**：让目录下**新创建**的文件自动继承目录的 ACL 权限。
- **设置**（在目录上）：
```bash
setfacl -m d:u:用户名:权限 目录
setfacl -m d:g:组名:权限 目录
```
- **特点**：
    - 对目录本身无效，只作用于新建的子文件/子目录。
    - 普通文件创建时不会自带 `x` 权限，因此继承后的 mask 可能自动去掉 `x`。
- **查看**：`getfacl` 中会显示 `default:` 开头的条目。
- **删除默认 ACL**：
```bash
setfacl -k 目录
```

#### 7.注意事项
- 修改文件基本权限（`chmod`）时，更改 **owner** 或 **other** 正常，更改 **group** 实际会修改 **mask**，而非原来的组权限。
- 若要修改拥有组的基本权限，应使用 `setfacl -m g::权限`。

## I/O 重定向和管道符

| **编号** | **名称**   | **描述** | **默认设备** | **用法** |
| ------ | -------- | ------ | -------- | ------ |
| 0      | stdin    | 标准输入   | 键盘       | 仅读取    |
| 1      | stdout   | 标准输出   | 终端       | 仅写入    |
| 2      | stderr   | 标准错误输出 | 终端       | 仅写入    |
| 3+     | filename | 其他文件   | 无        | 读取或写入  |

### 输出重定向

- 将屏幕上的正确输出信息重定向到文件中
```bash
`>`：将屏幕上的正确输出信息重定向到文件中（以覆盖的形式写入到文件中）
`>>`：将屏幕上的正确输出信息重定向到文件中（以追加的形式写入到文件中）
```

- 将屏幕上的错误输出信息重定向到文件中
```bash
`2>`：将屏幕上的错误输出信息重定向到文件中（以覆盖的形式写入到文件中）
`2>>`：将屏幕上的错误输出信息重定向到文件中（以追加的形式写入到文件中）
```

- 将屏幕上的所有输出信息重定向到文件中
```bash
`&>`：将所有的输出信息写入到文件中（覆盖）
`&>>`：将所有的输出信息写入到文件中（追加）
```


### 输入重定向
```bash
`<`：将文件中的内容输入重定向到指定的地方
```
- 示例：
```bash
[root@xym opt]# passwd devops < pass.txt
###提前把命令写入到文件中，然后直接基于文件来执行这些命令
```

### echo命令和管道符

管道符作用：连接多个命令的，可以将前面命令的输出信息作为后面命令的参数使用

```bash
命令1 | 命令2 | 命令3 ....
```

echo命令：echo命令后面接什么，屏幕上就会输出什么

```bash
echo 1 | passwd --stdin root
###修改root的密码为1
```
## Vim 编辑器

![](https://oss.bwihz.cn/PicGo/20260830005554301.png)
##### 命令模式
- 光标的移动：单个字符的移动、行的移动
	- 方向键的`↑` `↓` `←` `→`
	- 字母键的`h` `j` `k` `l`
	- 行的快速跳转：
		- `gg`：快速跳转到第一行
		- `G`：跳转到文件的末尾行
		- `6G`：跳转到第6行
- 向下翻一页：`pgdown` / `ctrl+f`
- 向上翻一页：`pgup`
- 跳转到光标所在行的头部：`HOME` / `ctrl+6`
- 跳转到光标所在行的尾部：`END` / `ctrl+4`
- `/关键字`：跳转到关键字,用于全文搜索
	- `/`：从上而下查找
	- `?`：从下而上查找
	- `n`：定位下一个匹配到的内容
	- `N`：定位上一个匹配到的内容  
- 字符的删除、行的删除
	- 单个字符的删除：`del` / `x`
	- 删除光标所在行：`dd`
	- `6dd`：删除6行内容
	- `d$`：删除光标所在行，光标后面所有的字符
	- `d^`：删除光标所在行，光标前面所有的字符
	- `dG`：删除光标以及光标后面所有的行的内容
- 复制、粘贴、撤销
	- `yy`：复制光标所在行的一整行内容
	- `6yy`：复制6行内容
	- `p`：粘贴到光标的下一行
	- `P`：粘贴到光标的上一行
	- `u`：撤销上一次操作
	- `Ctrl+r`：回退上一次撤销操作
	- `.`：重复操作
- 切换插入模式
	- `i`：在光标所在处切换
	- `a`：在光标后一个字符处切换
	- `I`：在光标所在行行首切换
	- `A`：在光标所在行行尾切换
	- `o`：在光标下一行切换
	- `O`：在光标上一行切换

##### 退出模式
>`shift + :`：切换退出模式
- 保存文件
	- `w`：保存
	- `wq` / `x`：保存并且退出
	- `wq!`：强制保存并且退出（只有文件的拥有人可以强制保存自己的文件，或者root用户）
- 不保存文件退出
	- `q`：退出
	- `q!`：强制退出（只要没有保存，强制退出之后再次打开，文件还是老样子）
- 另存为文件
	- `w 文件路径`：另存为
- 关键字替换  
	- `s/匹配关键字/替换后的关键字`：替换光标所在行的关键字
	- `ns/匹配关键字/替换后的关键字`：替换指定行的关键字
	- `%s/匹配关键字/替换后的关键字`：替换文件中所有行的关键字
	*不加g每一行只替换第一个匹配到的关键字，如需替换所有匹配到到关键字则需要在后面加上`/g`表示全局替换*

- 显示行号：
	- `set number`
- 取消显示
	- `set nonumber`
- 跳转到第6行：
	- `:6`
- 保留格式粘贴：
	- `set paste`
- 忽略大小写：
	- `set ignorecase`
- 取消忽略：
	- `set ignorecase`

##### 可视化模式
`Ctrl + v`：切换到可视化模式

批量添加内容 ：ctrl v 选中要添加内容的行 按I切换到编辑模式 输入你要添加的内容 按ESC
##### 多窗口模式
在一个文本编辑器中打开多个窗口，可以把一个文件打开多个窗口，也可以每个窗口是不同的文件

`:vsp`：纵向打开

多个窗口之间切换：先按'ctrl w'，**然后按方向键**
