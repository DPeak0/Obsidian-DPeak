## Redis配置与系统守护进程
```bash
[root@node1 ~]# mkdir /etc/redis
[root@node1 ~]# mkdir /var/log/redis
[root@node1 ~]# mkdir /var/lib/redis

[root@node1 ~]# cp ./redis-7.2.4/redis.conf /etc/redis/6379.conf

```
### 修改Redis配置文件
```bash
[root@node1 ~]# vim /etc/redis/6379.conf
# 绑定所有网段
  87 bind 0.0.0.0
  
# 允许后台守护进程运行
 309 daemonize yes 
 
# 设置日志文件路径
 355 logfile "/var/log/redis/redis.log"
 
# 设置工作目录 (dump.rdb 等持久化文件会存放在这里)
 510 dir /var/lib/redis
 
# 设置连接密码
1044  requirepass Redis@123

```
### 编写systemd服务文件
```bash
[root@node1 ~]# cat > /etc/systemd/system/redis.service << EOF
> [Unit]
> Description=Redis In-Memory Data Store
> After=network.target
>
> [Service]
> # 告诉 systemd Redis 将以守护进程方式在后台运行
> Type=forking
> # 指定启动命令及配置文件
> ExecStart=/usr/local/redis/bin/redis-server /etc/redis/6379.conf
> # 指定停止命令 (注意需带上密码参数)
> ExecStop=/usr/local/redis/bin/redis-cli -h 127.0.0.1 -p 6379 -a "Redis@123" shutdown
> Restart=always
>
> [Install]
> WantedBy=multi-user.target
> EOF

```

# 四、完成授课笔记中AOF持久化实验.
## 开启AOF机制
```bash
[root@node1 ~]# vim /etc/redis/6379.conf
1387 appendonly yes
```
- 重启Redis服务使配置生效
```bash
[root@node1 ~]# systemctl restart redis.service
```
## 模拟宕机
```bash
[root@node1 ~]# redis-cli -a "Redis@123"
127.0.0.1:6379> SET aof:safe:data "I am fully protected by AOF!"
OK
127.0.0.1:6379> exit
[root@node1 ~]# kill -9 $(pidof redis-server)
```
## 验证：数据仍然存在
```bash
[root@node1 ~]# redis-cli -a "Redis@123"
127.0.0.1:6379> GET aof:safe:da
"I am fully protected by AOF!"
```
