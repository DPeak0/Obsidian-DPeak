# LVM快照实战案例
- 准备工作：准备一个20G的磁盘，当作pv加入到vg0卷组中
```bash
[root@dpeak ~]# pvcreate /dev/sdc
Physical volume "/dev/sdc" successfully created.
[root@dpeak ~]# vgcreate vg0 /dev/sdc
Volume group "vg0" successfully created
[root@dpeak ~]# vgs
  VG  #PV #LV #SN Attr   VSize   VFree
  vg0   1   1   0 wz--n- <20.00g <19.00g

```

```bash
[root@dpeak ~]# lvcreate -n lv1 -L 1G vg0
```

- 拷贝/etc/passwd /etc/shadow /etc/group /etc/gshadow文件到/lv1中
```bashs
[root@dpeak ~]# cp /etc/passwd /etc/shadow /etc/group /etc/gshadow /lv1
[root@dpeak ~]# ls /lv1/
group  gshadow  passwd  shadow

```
- 给这个lv1拍摄一个快照，快照的名字为lv1-snap，cow空间大小为100M
  ```bash
  [root@dpeak ~]# lvcreate -n lv1-snap -s -L 100M /dev/vg0/lv1
  Logical volume "lv1-snap" created.
[root@dpeak ~]# lvs
  LV       VG  Attr       LSize   Pool Origin Data%  Meta%  Move Log Cpy%Sync Convert
  lv1      vg0 owi-aos---   1.00g
  lv1-snap vg0 swi-a-s--- 100.00m      lv1    0.00

  ```
- 创建好之后，请你删除原卷中的所有文件，并且基于快照进行数据还原
	  验证：还原之后，重新挂载原卷也就是lv1，数据文件还是存在的
```bash
[root@dpeak ~]# rm -rf /lv1/*
[root@dpeak ~]# umount /lv1

[root@dpeak ~]# mkdir /lv1-snap
[root@dpeak ~]# mkdir /lv1-back
[root@dpeak ~]# mount /dev/vg0/lv1-snap /lv1-snap/
[root@dpeak ~]# cp -a /lv1-snap/* /lv1-back/
[root@dpeak ~]# umount /lv1-snap

[root@dpeak ~]# mount /dev/vg0/lv1 /lv1
[root@dpeak ~]# cp -a /lv1-back/* /lv1/
[root@dpeak ~]# ls /lv1
group  gshadow  passwd  shadow

```

- 配置快照的自动扩容，要求当cow空间使用到了50%的时候，则自动扩容50%空间
	验证：你把/usr/sbin目录拷贝到/lv1中，通过lvs查看cow空间的大小
```bash

[root@dpeak ~]# vim /etc/lvm/lvm.conf
snapshot_autoextend_threshold = 50
snapshot_autoextend_percent = 50
```

# rpm 管理工具实战例题：
1. 前往 rpmfind.net 网站，下载 vsftpd 的 rpm 包到 Linux 主机的/opt 目录下
![](https://oss.bwihz.cn/%20PicGo/20260915161857976.png)

```bash
[root@dpeak ~]# cd /opt
[root@dpeak opt]# ls
vsftpd-3.0.3-36.el8.x86_64.rpm

```

2. 将其ISO 镜像文件挂载给 Linux 系统的/media 目录下，把这个目录下的 AppStream 目录下的 Packages 目录中的vsftpd 的 rpm 包拷贝到/opt 目录下
```bash
[root@dpeak opt]# mount /dev/sr0 /media/
mount: /media: WARNING: device write-protected, mounted read-only.
[root@dpeak opt]# cp -a /media/AppStream/Packages/vsftpd-3.0.3-33.el8.x86_64.rpm /opt/
[root@dpeak opt]# ls
vsftpd-3.0.3-33.el8.x86_64.rpm  vsftpd-3.0.3-36.el8.x86_64.rpm

```

3. 安装低版本的rpm 包，并且查询包是否安装
```bash
[root@dpeak opt]# rpm -ivh vsftpd-3.0.3-33.el8.x86_64.rpm
warning: vsftpd-3.0.3-33.el8.x86_64.rpm: Header V4 RSA/SHA256 Signature, key ID 6d745a60: NOKEY
Verifying...                          ################################# [100%]
Preparing...                          ################################# [100%]
Updating / installing...
   1:vsftpd-3.0.3-33.el8              ################################# [100%]
[root@dpeak opt]# rpm -q vsftpd
vsftpd-3.0.3-33.el8.x86_64


```

4. 列出当前已经安装的所有的软件包，同时列出vsftpd软件包安装之后会释放的配置文件有哪些
```bash
[root@dpeak opt]# rpm -qa && rpm -qc vsftpd
```

5. 将其 vsftpd 版本进行更新升级
```bash
[root@dpeak opt]# rpm -Uvh vsftpd-3.0.3-36.el8.x86_64.rpm
warning: vsftpd-3.0.3-36.el8.x86_64.rpm: Header V4 RSA/SHA256 Signature, key ID c21ad6ea: NOKEY

```

6. 将其版本进行降级，最后再次查询软件包版本
```bash
[root@dpeak opt]# rpm -Uvh --oldpackage vsftpd-3.0.3-33.el8.x86_64.rpm
warning: vsftpd-3.0.3-33.el8.x86_64.rpm: Header V4 RSA/SHA256 Signature, key ID 6d745a60: NOKEY

[root@dpeak opt]# rpm -q vsftpd

```
