1.执行df命令,去掉显示的第一行内容,将其输出信息另存为到/opt/filesystem文件中
```bash
df | tail -n +2 > /opt/filesystem
```
2.执行last命令,去掉末尾的2行内容,将剩余内容另存为到/opt/lastlog文件中
```bash
last | head -n -2 > /opt/lastlog
```
3.统计出系统上可以登录的用户数量
```bash
grep -c /bin/bash$ /etc/passwd
```
4.仅过滤出devops用户的信息,其余都不显示
```bash
grep -w devops /etc/passwd
```
5.过滤出/var/log/messages文件中包含err关键字的行,并且忽略其大小写进行过滤,同时还要显示所在行的前后6行内容
```bash
grep -i -C6 err /var/log/messages
```
6.找出系统上所有不可以登录的用户,将其用户信息打印到屏幕上
```bash
grep -v /bin/bash$ /etc/passwd
```
