## 配置主库Master(node1)
- 创建主库自定义配置文件
```bash
[root@node1 ~]# vim /etc/my.cnf.d/replication.cnf
[root@node1 ~]# cat /etc/my.cnf.d/replication.cnf
[mysqld]
# 监听所有网卡接口
bind-address = 0.0.0.0
# 集群内唯一节点 ID
server-id = 1
# 开启二进制日志
log-bin = mysql-bin
# Binlog 格式使用 ROW（数据一致性最高，最佳实践）
binlog_format = ROW
```
- 重启MySQL使配置生效
```bash
[root@node1 ~]# systemctl restart mysqld.service
```


- 创建数据同步专用账号
```mysql
mysql> CREATE USER 'repl'@'192.168.0.%' IDENTIFIED BY 'Repl@123456';
Query OK, 0 rows affected (0.01 sec)

mysql> GRANT REPLICATION SLAVE ON *.* TO 'repl'@'192.168.0.%';
Query OK, 0 rows affected (0.01 sec)

mysql> FLUSH PRIVILEGES ;
Query OK, 0 rows affected (0.00 sec)
```

- 记录主库当前的Binlog坐标

## 配置从库Slave(node2)
- 创建MySQL从库自定义配置文件
```bash
[root@node2 ~]# vim /etc/my.cnf.d/replication.cnf
[root@node2 ~]# cat /etc/my.cnf.d/replication.cnf
[mysqld]
bind-address = 0.0.0.0
# 从库 ID 必须与主库不同
server-id = 2
# 开启中继日志
relay-log = mysql-relay-bin
# 开启全局只读模式 (非 SUPER 权限用户无法写入数据)
read_only = 1
```
- 重启使配置生效
  ```bash
  [root@node2 ~]# systemctl restart mysqld.service
  ```

>[!注意]
>VMware虚拟机克隆会导致`server_uuid`一样，从而导致以下报错：
>`Last_IO_Errno: 13117`
>`Last_IO_Error: Fatal error: The slave I/O thread stops because master and slave have equal MySQL server UUIDs; these UUIDs must be different for replication to work`
>`server_uuid` 保存在数据目录下的 `/var/lib/mysql/auto.cnf` 里
>解决办法：停止MySQL服务，删除`/var/lib/mysql/auto.cnf`文件后重新启动MySQL会自动重新生成
>

# 两台MySQL服务器的双主复制实验
## 双主防冲突配置
### node1
- 修改MySQL自定义配置文件
```bash
[root@node1 ~]# cat /etc/my.cnf.d/replication.cnf
[mysqld]
# 监听所有网卡接口
bind-address = 0.0.0.0
# 集群内唯一节点 ID
server-id = 1
# 开启二进制日志
log-bin = mysql-bin
# Binlog 格式使用 ROW（数据一致性最高，最佳实践）
binlog_format = ROW
# 双主防冲突：步长与偏移量
auto_increment_increment = 2
auto_increment_offset = 1

```
- 重启MySQL使配置生效
  ```bash
  [root@node1 ~]# systemctl restart mysqld
  ```

### node2
- 修改MySQL自定义配置文件
```bash
[root@node2 ~]# cat /etc/my.cnf.d/replication.cnf
[mysqld]
bind-address = 0.0.0.0
server-id = 2
relay-log = mysql-relay-bin
# 开启 Binlog（作为主库必备）
log-bin = mysql-bin
binlog_format = ROW
# 双主防冲突：步长与偏移量
auto_increment_increment = 2
auto_increment_offset = 2
```
- 创建数据同步专用账号
