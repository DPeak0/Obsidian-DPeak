# Shell 脚本(bash)

#### shell自带的变量

```bash
PATH: 指定命令的搜索路径
HOME: 指定用户的工作目录（即用户登录到linux系统中时，默认的目录）
HISTSIZE： 保存历史命令的条数
LOGNAME: 当前用户的登录名
HOSTNAME：主机的名称
SHELL：指当前用户用的是哪种shell
LANG/LANGUGE： 和语言相关的环境变量，使用多种语言的用户可以修改此环境变量
MAIL：指当前用户的邮件存放目录
```

#### 简短举例

```bash
root@debian:/shell# vim 1.sh 
#!/bin/bash
echo "Hello World!"
root@debian:/shell# sh 1.sh 
Hello World!
```
