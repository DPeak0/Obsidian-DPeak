# Mariadb/MySQL 数据库基本配置

####  安装服务端软件包

```bash
[root@data ~]# yum install -y mariadb-server
[root@data ~]# systemctl start mariadb # 启动数据库
[root@data ~]# systemctl enable mariadb # 设置开机自启
```

#### 配置中文编码支持

```bash
[root@data ~]# vim /etc/my.cnf.d/server.cnf
[mysqld]
character_set_server=utf8
```

##### 修改数据库字符集

```mysql
ALTER DATABASE 数据库名 CHARACTER SET utf8;
```

##### 修改表字符集

```mysql
ALTER TABLE 表名 CONVERT TO CHARACTER SET utf8;
```

##### 修改列字符集

```mysql
ALTER TABLE 表名 MODIFY 列名称 VARCHAR(255) CHARACTER SET utf8;
```

#### 连接mariaDB

```bash
[root@data ~]# mysql -u用户名 -p密码
```

#### 创建数据库

```mysql
MariaDB [(none)]> CREATE DATABASE myDB;
```

#### 删除数据库

```mysql
MariaDB [(none)]> drop database 数据库名;
```

#### 查看数据库

```mysql
MariaDB [(none)]> show databases;
+--------------------+
| Database           |
+--------------------+
| information_schema |
| myDB               |
| mysql              |
| performance_schema |
+--------------------+
4 rows in set (0.00 sec)
```

#### 进入数据库

```mysql
MariaDB [(none)]> USE myDB;
```

#### 创建表

```mysql
MariaDB [myDB]> CREATE TABLE baseinfo (
    ->   studentID int NOT NULL PRIMARY KEY,
    ->   name varchar(10),
    ->   sex char(1) DEFAULT 'M',
    ->   birthday date,
    ->   school char(20)
    -> );
```

#### 删除表

```mysql
MariaDB [myDB]> drop table 表名;
```

#### 查看表

```mysql
MariaDB [myDB]> show tables;
+----------------+
| Tables_in_myDB |
+----------------+
| baseinfo       |
+----------------+
```

#### 插入数据

通常是使用 “M” 表示男性，”F” 表示女性

```mysql
MariaDB [myDB]> INSERT INTO baseinfo VALUES(
1,'一','M','2001-1-1','国土'),
(2,'二','F','2002-2-2','国土'),
(3,'三','M','2003-3-3','国土'),
(4,'四','F','2004-4-4','国土'),
(5,'五','M','2005-5-5','国土');
```

#### 删除数据

```mysql
MariaDB [myDB]> delete from 表名;		##删除全部
MariaDB [myDB]> delete from baseinfo where studentID=5; ##指定删除
```

#### 更新数据

```mysql
MariaDB [myDB]> update baseinfo set name ='六' where studentID=5 ;
```
