### Linux常用目录
- **/home**：_家目录/home/admin /home/user1_
- **/root**：_root用户的家目录_将屏幕上的**正确输出信息**重定向到文件中
- **/usr**：_系统安装的软件存放的目录_
- **/usr/bin**：_普通用户可以执行的命令_
- **/usr/sbin**：_管理员才能执行的命令 bin: binary 二进制程序 可执行程序 由源代码编译过，可以直接执行的程序_
- **/etc**：_存放配置文件_
- **/tmp**：_temp临时文件_
- **/boot**：_500MB 存放内核文件 引导程序_
- **/var**：_经常变化的数据 日志文件/var/log /var/www/html_
- **/dev** ：_设备文件 /dev/sda1 第一块 SCSI 硬盘的第一个分区_
- **/lib**：_驱动程序 第三方库_
- **/proc /sys** ：_内存中的数据 调优_

### /etc/passwd 用户信息文件

```
name:password:UID:GID:GECOS:directory:shell
```

### /etc/shadow 用户密码文件

```
user1:$6$SC4sCLGWR07WYlDA$Xwff0f5LG14lQMFIC9nzlVtP9iZFwyg8fq609oiuWElucFEccpQkxN2jhTdzVvcWTpkMyv2oUI7SH0gHF.1Vi//:20527:0:99999:7: : :
```

`用户名` ：`密码(hash加密)`：`密码最后变更时间(从1970-01-01开始计算天数)` ：`密码最小过期时间` ：`密码最大过期时间` ：`密码过期前的警告天数`：`密码过期后再经过多少天会锁定,密码如果密码被锁定了，则用户无法登录`：`账户的失效日期：单位是天数，并且是从1970-01-01开始计算`：

### /etc/group：用户组信息文件

```
group_name:password:GID:user_list
```

`group_name`：组的名字

`password`：组的密码占位符，表示登录这个组是否需要密码验证（如果是x表示需要验证，如果没有x表示不需要密码验证）组是可以被登录的

`GID`：组的ID，gid

`user_list`：组内的成员（如果这个组是用户的附加组，那么这里会看到成员）

### /etc/gshadow 用户组密码文件

```
group_name:::
```
第一列：组的名字
第二列：组加密后的密码，采用的sha512方式
第三列：组的管理员（管理员可以修改组的密码，并且管理组的成员-添加用户到组，删除组的成员）
第四列：组的成员

### `/etc/sudoers` 权限委派配置文件

除了可以将配置写入到/etc/sudoers文件中，还可以写入到/etc/sudoers.d目录下

```
Cmnd_Alias USERMODS = /usr/sbin/useradd,/usr/sbin/usermod,/usr/sbin/userdel,/usr/sbin/groupadd,/usr/sbin/groupdel,/usr/sbin/groupmod,/usr/bin/passwd     ###命令别名
User_Alias ADMINS = user1,user2     ###用户别名

## Allow root to run any commands anywhere
root    ALL=(ALL)       ALL
alice   ALL=(root)      /usr/sbin/useradd
允许哪个用户使用sudo命令  允许在哪个主机上执行sudo命令=(允许提权到哪个用户身份) 允许提权之后执行什么命令
```

# 网络管理

## `/etc/sysconfig/network-scripts/ifcfg-*` 网卡配置文件
配置文件必须是ifcfg-xxx开头
```bash
TYPE=Ethernet    #类型，以太网      双网卡bond技术 bond   桥接网络 bridge
BOOTPROTO=dhcp    #获取ip地址的方式 dhcp表示自动分配，none/static 手动分配
IPADDR=192.168.200.128      #ipv4地址
PREFIX=24 或 NETMASK=255.255.255.0  #子网掩码     
GATEWAY=      #网关地址
DNS1=
DNS2=         #DNS地址 
DEFROUTE=yes    #是否将网关作为默认网关
NAME=ens160    #网卡配置文件名字（connection 连接）  
DEVICE=ens160    #配置文件绑定给哪个网卡设备
ONBOOT=yes    #开机自动激活网卡设备和配置

UUID=     #网络接口的唯一标识符

```
