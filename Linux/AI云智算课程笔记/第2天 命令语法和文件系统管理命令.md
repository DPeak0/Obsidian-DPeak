# 8.25 命令语法和文件系统管理命令

### 一、语法

#### 命令三要素：

- 命令：要实现的功能（useradd命令创建用户、passwd命令修改密码等）
- 选项：对命令功能的补充，以 `-`（短格式）或 `--`（长格式）开头
- 参数：命令操作的对象（用户名、文件名、设备名等）

#### 命令书写规范：

> 命令 选项 选项的参数 参数

- 命令一定在选项和参数的最前面
- 命令和选项之间使用空格隔开
- 选项和参数之间使用空格隔开
- 选项和选项之间使用空格隔开
- 参数和参数之间使用空格隔开

```bash
 useradd [options] LOGIN
```

[ ] ： 表示可选

大小字母：表示必填

...：表示可以接多个

a|b|c：多选一

< > ：表示有默认值，可以省略。如果你写了那么就是覆盖

# Linux文件系统结构和管理文件的命令

## 文件系统结构

所谓的文件系统结构：就是一个专业话语而已，对于我们来说其实就是有哪些目录，这些目录有什么作用

Linux系统文件系统结构：呈现的**单根倒树枝结构，**一切的一切都是从/ 根目录出发，如果/根目录故障存在问题，则整个操作系统都无法运行

## Linux系统常用目录的作用

**一切皆文件：你看到的所有东西最终在操作系统上都是以文件的形式展现给你的**

```text
[root@dpeak ~]# ls /
bin   dev  home  lib64  mnt  proc     root  sbin  sys  usr
boot  etc  lib   media  opt  project  run   srv   tmp  var
```

**/boot**：启动的时候会读取目录下的文件，来启动启动（启动引导目录，主要作用就是开机的时候会加载这个目录下的文件来帮助启动系统）

**/bin**：binary（二进制），我们执行的所有的命令实际上都是二进制文件，目录下保存的都是普通用户可以执行的命令文件

**/sbin**：超级管理员可以执行的命令文件

  /bin是/usr/sbin的快捷方式

  /sbin是/usr/sbin的快捷方式

/dev：device设备，保存的是系统的设备文件，例如键盘鼠标磁盘等...

**/etc**：保存的是系统的配置信息，比如系统主机名、网卡配置文件、应用程序的配置文件、用户账户文件、用户的密码文件...

/home：保存的是普通用户的家目录，保存普通用户个人数据的目录

/lib和/lib64：保存的是系统上执行命令的时候调用的依赖库文件

  /lib是/usr/lib的快捷方式

  /lib64是/usr/lib64的快捷方式

/media和/mnt：空目录，做临时挂载点使用的

/opt：空目录，保存的是第三方下载的安装包软件（等价于windows的下载）

/proc：process进程（系统上运行一个软件，系统后台就有进程）目录下保存的都是系统中的进程信息

**/root**：root用户的家目录

/run：系统在运行的时候产生的数据保存到这个目录下，一旦重启，数据丢失，所以不建议永久保存文件到这个目录

/srv：service 空目录，保存系统服务的文件，例如网站的网页文件

/sys：system系统，系统在运行的时候产生的数据保存到这个目录下，一旦重启，数据丢失，所以不建议永久保存文件到这个目录

/tmp：临时目录，系统上运行软件的时候，软件会产生临时数据会保存到这个目录下

/usr：系统核心目录

  /usr/sbin /usr/bin /usr/lib /usr/lib64

  /usr/local：安装第三方软件的时候，将软件的安装位置放到这个目录下

/var：保存的是系统变化的文件，例如ftp服务器共享目录，例如系统的日志文件

## 文件的路径

文件的路径：这个文件在哪里

- 相对路径：不以/开头的路径。相当于当前目录来搜索文件
- 绝对路径：以/开头的路径。在系统上任意位置都可以使用绝对路径
