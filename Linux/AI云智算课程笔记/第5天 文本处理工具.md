# cat命令-打印输出文件的内容

原来查看文件的内容，通过vim命令查看

- 打印文件所有内容到屏幕上

```Markdown
cat 文件

常用选项：
  cat -n 文件：打印行数
  cat -A 文件：显示隐藏符号
    很多情况下，我们编辑文件的时候可能不是直接在Linux系统上编辑的，而是在windows或者macos上编辑的文件，最后通过传输工具，将windows或者macos上的文件传输给Linux

```
- 整合多个文件到一个新的文件
    - 将/etc/passwd和/etc/group文件整合到/opt/new文件

```Bash
[root@xym ~]# cat /etc/passwd /etc/group > /opt/new

```

    **借助重定向符号实现的**
- cat配合输入重定向生成带有内容的文件

    通常情况下，这种命令会应用在自动化场景下，也就是说一回车就立即生成带有内容的文件，而不是像vim编辑器这样需要使用键盘上的很多按键才能使用。当你想要通过一条命令回车立即生成带有内容的文件，都可以使用这个方式

    案例：要求通过cat和重定向符号生成一个/opt/cat文件，内容如下

    name=个人姓名缩写（xym）

    age=100

```Bash
cat > /opt/cat <<AAA
name=xym
age=100
AAA
```

# 正则表达式

grep命令本身支持很多方式的过滤，但是如果要求你过滤以root关键字开头的行，grep本身无法实现，需要借助正则表达式的元字符来实现

```Bash
[root@xym ~]# grep ^root /etc/passwd 
root:x:0:0:root:/root:/bin/bash

```

- 基本正则表达式
- 扩展正则表达式
- 区别在于：扩展正则表达式支持的元字符更多

**所谓的正则表达式，就是通过不同的元字符实现不同规律的过滤**

下面是基本正则表达式的元字符

- ^：以某关键字开头的

```Bash
grep ^memeda /etc/passwd 
```
- $：以某关键字结尾的

```Bash
grep /sbin/nologin$   /etc/passwd
```
- \<：在字的开头（单词）
- \>：在字的末尾（单词）

```Bash
[root@xym ~]# grep '\<devops' /etc/passwd 
devops:x:1000:1000:devops/bin/bash:/home/123devops:/bin/bash

[root@xym ~]# grep 'devops\>' /etc/passwd 
devops:x:1000:1000:devops/bin/bash:/home/123devops:/bin/bash

```
- .：匹配任意单个字符
- \：去掉后面单个字符的特殊意义

```Bash
[root@xym ~]# grep '\.' file.txt 
name11.memeda

```
- [ ]:匹配括号内部的任意单个字符
    - 匹配字母[a-z][A-Z]

```Bash
[root@xym ~]# grep '[abc]' file.txt 

```
    - 匹配数字[0-9]
    - 对括号内部关键字取反:[^abc123]
    - *:对前面一项进行0次或者多次匹配



下面是扩展正则的元字符:

  扩展正则的元字符包含基本正则的元字符,但是比它要多

  如果grep命令想要使用扩展的元字符的话,必须要加上-E选项,或者使用egrep命令

```Bash
grep -E
egrep

```

- ?:对前面一项匹配0次或者1次

```Bash
[root@xym ~]# grep -E 'ro?' /etc/passwd 

```
- +:对前面一项匹配1次或者多次

```Bash
[root@xym ~]# grep -E 'ro+' /etc/passwd 

```

```Bash
[root@xym ~]# #grep -E 'ro*' /etc/passwd  ---> 对前面的o匹配0次或者多次
[root@xym ~]# #grep -E 'ro?' /etc/passwd  ---> 对前面的o匹配0次或者1次
[root@xym ~]# #grep -E 'ro+' /etc/passwd  ---> 对前面的o匹配1次或者多次

```
- {}:表示一个范围进行匹配,对前面一项匹配指定的次数
    - {n,m}:对前面一项最少匹配n次,最多匹配m次
    - {m}:对前面一项匹配m次
    - {n,}:对前面一项最少匹配n次
    - {,m}:对前面一项最多匹配m次
- ():把括号内的所有内容当作一整项
- |:匹配多个关键字

# sed-流编辑器

sed的作用和vim的作用一模一样,vim能够做的,sed也能够做

sed属于非交互式编辑,vim属于交互式编辑

而sed作为非交互式的编辑工具来说,在自动化脚本中频繁出现,只要在脚本中要编辑文件的,不会使用vim,一定会使用sed

## sed的工作流程

stream edit:流编辑器

处理文件的时候,从上往下依次处理,处理一行就输出一行

sed处理文件的时候,会将文件的所有内容加载到模式空间,然后根据你的操作,对模式空间的内容进行操作,处理一行就输出一行

![](https://secure2.wostatic.cn/static/pBR852pgn2eACMXpv6w9ZA/image.png?auth_key=1788344860-w5GQBZHCbubQmh1g9jsjyo-0-75e0d187bca1505b474a6d263f53484c)

```Bash
[root@xym ~]# sed '1p' file.txt
1
1
2
3
4
5
[root@xym ~]# sed '2p' file.txt
1
2
2
3
4
5

```

**sed默认情况下,处理文件的时候对源文件不受影响**

-i选项:对源文件影响

-i.bak:先对源文件备份,备份后的文件名.bak,然后再编辑源文件内容(推荐的,安全)

-r:默认支持基本正则,-r表示支持扩展正则表达式

-e:支持接多个sed处理

-n:不要输出模式空间的内容





sed支持的功能:

打印输出
关键字替换
关键字删除
行的删除
追加内容

增删改查



## 地址定界:告诉sed要处理的行数

1. n:直接写数字,表示告诉sed要处理第几行内容
2. $:匹配最后一行
3. n,m:匹配n行到m行

```Bash
[root@xym ~]# sed -n '25,30p' /etc/passwd
clevis:x:994:988:Clevis Decryption Framework unprivileged user:/var/cache/clevis:/sbin/nologin
usbmuxd:x:113:113:usbmuxd user:/:/sbin/nologin
unbound:x:993:987:Unbound DNS resolver:/etc/unbound:/sbin/nologin
gluster:x:992:986:GlusterFS daemons:/run/gluster:/sbin/nologin
rpc:x:32:32:Rpcbind Daemon:/var/lib/rpcbind:/sbin/nologin
avahi:x:70:70:Avahi mDNS/DNS-SD Stack:/var/run/avahi-daemon:/sbin/nologin

```
4. /关键字/:匹配关键字所在的行(支持正则表达式的)

```Bash
[root@xym ~]# sed -n '/^root/p'  /etc/passwd 
root:x:0:0:root:/root:/bin/bash
[root@xym ~]# grep ^root /etc/passwd 
root:x:0:0:root:/root:/bin/bash

```

```Bash
[root@xym ~]# sed -n '/dns/p' /etc/passwd 
dnsmasq:x:983:983:Dnsmasq DHCP and DNS server:/var/lib/dnsmasq:/sbin/nologin

```

    匹配的过程中,支持忽略大小写

```Bash
[root@xym ~]# sed -n '/dns/Ip' file.txt
dns
dNS

```
5. \%关键字%:匹配关键字所在的行

```Bash
[root@xym ~]# sed -n '\%/bin/bash%p' /etc/passwd 
root:x:0:0:root:/root:/bin/bash
devops:x:1000:1000:devops/bin/bash:/home/123devops:/bin/bash
```





## 处理动作:对匹配的行做什么操作

p:打印输出

d:删除匹配的行

```Bash
#删除文件最后一行内容
[root@xym ~]# sed -i '$d' /etc/passwd.bak 

#删除指定行的内容
[root@xym ~]# sed -i '18,21d'   /etc/passwd.bak

#删除/etc/passwd.bak文件中包含root关键字的行
[root@xym ~]# sed -i '/root/d' /etc/passwd.bak

```

a\:在匹配行的下一行新增内容

```Bash
[root@xym ~]# sed -i '43a\PermitRootLogin no' /etc/ssh/sshd_config

```

i\:在匹配行的上一行新增内容

s/匹配关键字/替换后的关键字/
  - i：忽略关键字大小写
  - g：实现全局替换，默认仅会替换第一个匹配到的关键字

```Bash
[root@xym ~]# sed -i 's/^SELINUX=enforcing/SELINUX=disabled/' /etc/selinux/config 
#如果替换的关键字包含/，可以使用其他的符号来代替
[root@xym ~]# sed -i 's%/bin/bash%/sbin/nologin%'  /etc/passwd.bak 


[root@xym ~]# sed -i 's/dns//ig' /etc/passwd.bak 



```
