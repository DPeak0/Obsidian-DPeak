## shell
### Shell 概述

- **Shell 的作用**：Linux 中的**命令解释器**，将用户输入的命令翻译为内核能理解的语言。没有 Shell，用户无法执行任何命令。
- **登录 Shell 程序**：用户在 `/etc/passwd` 中最后一列指定（如 `/bin/bash`），即用户登录后默认使用的 Shell。
- **执行流程**：  
    用户执行命令 → 交给 Shell → 内核
![](https://oss.bwihz.cn/%20PicGo/20260901200315470.png)
- 常见的 Shell 程序

| Shell | 说明                    |
| ----- | --------------------- |
| bash  | 主流 Shell，大多数 Linux 默认 |
| sh    | 早期 Shell，通常软链接到 bash  |
| csh   | C 语言风格的 Shell         |
| ksh   | Korn Shell            |

- **查看当前使用的 Shell**：`echo $SHELL`
```bash
[root@dpeak ~]# echo $SHELL
/bin/bash
```
- **查看系统支持的 Shell**：`cat /etc/shells`
```bash
[root@dpeak ~]# cat /etc/shells
/bin/sh
/bin/bash
/usr/bin/sh
/usr/bin/bash
```
### Bash 的功能与快捷操作
#### 1. 历史记录（history）
- 查看历史命令：`history`
- 历史记录默认存储在**内存**中，重启会丢失。
- 保存历史到磁盘（`~/.bash_history`）：`history -w`
- **快速调用历史命令**：
    - `↑` / `↓` 方向键逐条翻找
    - `Ctrl + r`：交互式搜索（按关键字搜索最近一条，多次按跳转）
    - `!数字`：执行指定编号的历史命令
    - `!字符`：执行最近一条以该字符开头的命令
    - `Alt + .`：粘贴上一条命令的最后一个参数
#### 2. 常用快捷键

| 快捷键        | 功能            |
| ---------- | ------------- |
| `Ctrl + c` | 中断当前命令        |
| `Ctrl + z` | 暂停当前命令（可后台恢复） |
| `Ctrl + u` | 剪切光标前所有内容     |
| `Ctrl + y` | 粘贴剪切内容        |
| `Ctrl + k` | 剪切光标后所有内容     |
| `Ctrl + a` | 跳转到行首         |
| `Ctrl + e` | 跳转到行尾         |
| `Ctrl + w` | 剪切光标前的一个单词    |
| `Ctrl + s` | 暂停屏幕输出（命令仍执行） |
| `Ctrl + q` | 恢复屏幕输出        |
| `Ctrl + l` | 清屏（等同于 clear） |
|            |               |

#### 3. Tab 键补全
- 可补全**命令、选项、文件路径**等一切内容，按两次 Tab 显示所有可能。
#### 4. 重定向符号
输入重定向和输出重定向：
  [[1.Linux系统#输入重定向|输入重定向]]：从键盘上接受输入变成从文件中接受输入
  [[1.Linux系统#输出重定向|输出重定向]]：将屏幕上的输出信息重定向到文件中
#### 5. 管道符 `|`
- 格式：`command1 | command2`
- 作用：将前一个命令的**标准输出**作为后一个命令的输入。
#### 6. 通配符
通配符：用来匹配文件名称的
`*`：匹配所有
`?`：匹配任意单个字符

#### 7. 命令扩展符号
- `$()` 或  ` `` `  反引号 ：引用命令的执行结果
	```bash
	$(命令) 
	`命令`
	```
   
- `{ }`：批量生成范围
    - `{1..10}` → 1 2 3 ... 10（连续）
    - `{1,a,test}` → 1 a test（不连续）  
	示例：
	```bash
	[root@dpeak ~]# mkdir /opt/{1,2,3,4}
	```
### 登录 Shell 与 非登录 Shell

- 登录SHELL：图形登录、命令行登录、SSH登录、`su -` 切换用户
	- /etc/bashrc
	- /etc/profile
	- ~/.bashrc
	- ~/.bash_profile
- 非登录SHELL：图形化下的标签页、`su` 切换用户、执行自动化脚本
	- /etc/bashrc
	- ~/.bashrc

- 切换用户时要使用 `su - 用户名`，以保证完整加载变量文件。
- **永久定义变量/别名**：
  所有用户 → `/etc/bashrc`
  指定用户 → `~/.bashrc`
## 变量

### 1. 变量基础
- 变量由 **变量名** 和 **变量值** 组成，格式：`变量名=变量值`
- 变量占用内存空间，用于存储数据。
- **命名规则**：由字母、数字、下划线组成，**不能以数字开头**。
- 多次赋值同一个变量，新值会覆盖旧值。
### 2. 变量分类
- **本地变量**
    **作用域范围：当前SHELL中**
    **定义本地变量的方式**：变量名=变量值

- **环境变量**
	**作用域范围：当前SEHLL和子SHELL中**
	**定义环境变量的方式：**`export 变量名=变量值`
	将本地变量转化为环境变量：`export 本地变量`

- 系统变量：系统的一些变量，比如说PWD、HOME、USER
    PS1：决定当前终端上的命令提示符
    **PATH**：保存的是系统上命令文件的目录
### 3. 变量操作
- **引用变量**：`$变量名` 或 `${变量名}`
- **查看所有变量**（含本地+环境）：`set`
- **查看环境变量**：`env`
- **取消变量**：`unset 变量名`
### 4. 变量的永久生效
- **全局（所有用户）**：写入 `/etc/bashrc`（每次用户登录都会加载）
- **个人（仅当前用户）**：写入 `~/.bashrc`（仅该用户登录加载）
### 5. 转义字符

| 符号         | 作用                                 |
| ---------- | ---------------------------------- |
| `\`        | 转义其后单个字符（去掉特殊意义）                   |
| `" "`（双引号） | 弱引用，保留 `$`、`` ` ``、`!` 等特殊符号的功能 \| |
| `' '`（单引号） | 强引用，引号内所有字符均失去特殊意义（原样输出）           |

- 示例：
```bash
a=100
echo "$a"   # 输出 100
echo '$a'   # 输出 $a
```

## 别名（alias）

- **作用**：为长命令定义简短的别名，提高效率。
- **定义**：`alias 别名='命令'` 或 `alias 别名="命令"`
- **查看所有别名**：`alias`
- **取消别名**：`unalias 别名`
  
示例：

```bash
alias lsnet='ls -l /etc/sysconfig/network-scripts/'
alias cpetc='cp -r /etc /tmp/etc-$(date +%F)'
```
- 要使别名永久生效，写入 `/etc/bashrc`（全局）或 `~/.bashrc`（个人）。
