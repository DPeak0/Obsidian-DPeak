# 文件系统
## 基础概念

- 文件只能存储在文件系统上，而文件系统构建在块设备上。
![](https://oss.bwihz.cn/PicGo/20260912221011567.png)
- 块设备：磁盘、U盘、外接硬盘、分区等。
- 格式化：创建文件系统。新文件系统会覆盖旧文件系统，所以多次格式化会导致原有数据丢失。
- 挂载：将文件系统和某个目录关联起来，必须挂载到挂载点才能访问。
- 挂载点：本质是一个目录，是文件系统的访问入口。
- 分区：对物理存储空间划分逻辑上的存储空间，类似 Windows 的 C 盘、D 盘。
## 磁盘设备命名规则
| 磁盘类型         | 命名格式            | 示例                                                |
| ------------ | --------------- | ------------------------------------------------- |
| IDE 磁盘       | /dev/hdx        | `/dev/hda`、`/dev/hdb`、`/dev/hdc`                  |
| SCSI/SATA 磁盘 | /dev/sdx        | `/dev/sda`、`/dev/sdb`、`/dev/sdc`                  |
| NVME 磁盘      | /dev/nvme0nx    | `/dev/nvme0n1`、`/dev/nvme0n2`                     |
| KVM 虚拟磁盘     | /dev/vdx        | `/dev/vda`、`/dev/vdb`、`/dev/vdc`                  |
| XEN 虚拟磁盘     | /dev/xvdx       | `/dev/xvda`、`/dev/xvdb`                           |
| LVM 设备       | /dev/mapper/xxx | `/dev/mapper/rhel-root`、`/dev/mapper/centos-root` |
>想使用磁盘存储空间，需要在磁盘设备上创建文件系统
>Linux系统开机无法启动时，可在救援模式下修复系统


## 文件系统类型
### 本地文件系统
文件系统是保存到系统本地的，只有本机才能访问这个文件系统中的文件
- Windows：`NTFS`
- Linux：`XFS`、`ext4/ext3/ext2`
	主流的Linux默认本地文件系统类型要么是XFS要么是ext4
### 网络文件系统
通过网络的方式将文件远程存储到文件系统中
- `CIFS`：Windows 与 Windows、Windows 与 Linux 之间共享。
- `NFS`：Linux 与 Linux、Linux 与 Unix 之间共享。

### 光盘文件系统
光盘设备的文件系统
- `ISO9660`

## 文件系统的组成
文件系统主要由两部分组成：
- inode
	保存文件的**元数据信息**。
	元数据：描述数据的数据。
	inode 中保存：
	- 文件权限
	- 文件大小
	- 文件时间戳
	- 文件指针：指向数据块 block 的位置
- block
	真正存储文件数据的位置。
	系统上每个文件创建后，文件系统都会分配一个 inode。
	查看 inode：
	bash
	ls -li /etc/passwd
	示例：
	bash
	18169735 -rw-r--r--. 1 root root 1961 Sep  9 04:14 /etc/passwd
	说明：
	- `18169735` 就是该文件的 inode 编号。
	- 文件名不是系统真正识别的对象，系统主要识别 inode。
	- 类似系统不认识用户名，只认识 UID，用户信息在 `/etc/passwd`。
