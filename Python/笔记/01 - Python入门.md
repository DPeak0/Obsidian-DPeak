
## 数据存储与运算
### 字面量
字面量指程序中，直接书写的固定值（数据），就称为字面量。
- 数字类型：
	整数(int)：10 -5 0 1
	浮点数(float)：1.1 3.14 1.0 -3.5
- 布尔(bool)：True False 
- 字符串(str)：“Holler world”
- 空值(NoneType)：None
- 数据容器：列表/元组/集合/字典
说明：布尔类型本质是数字类型，在涉及到数学运算时会自动将True转为1，Flase转为0。
### 变量
程序中用来存储单个数据的容器，通常会把经常发生变化的数据存储在变量中。
定义格式：变量名1,变量名2 = 变量1的值,变量2的值
变量的使用：输出打印、参与计算、记录数据
注意事项：
- 一个变量只能存储一个值
- 变量定义的时候必须赋值才可以使用
- 一条语句可以多个变量，也可以连续赋值（a,b = 1,"Python"）
### 标识符
标识符是程序员在代码中为变量、函数、类等元素所起的名字。
命名规定：
- 1.只能包含字母(a-Z，A-Z）、数字（0-9）、下划线（ \_ )
- 2.不能以数字开头
- 3.不能使用关键字：True、False、None、and、or、if、else、elif、for、while等
- 4.严格区分大小写，比如：age，Age，AGE是三个变量
命名规范：
- 1.见名知意
- 2.多个部分使用下划线连接
- 3.英文字母全小写
### 数据类型
常见数据类型：

| 名称       | 描述  | 说明                      |
| -------- | --- | ----------------------- |
| int      | 整数  | 数字类型，存放整数，如：10、-5       |
| float    | 浮点数 | 数字类型，存放小数，如：3.14、-1.0   |
| str      | 字符串 | 用引号引起来的都是字符串，如：“Python” |
| bool     | 布尔  | 布尔类型，描述真和假：True、False   |
| NoneType | 空值  | 表示空或无值：None             |
type(...) 获取指定的字面量或变量的类型
isinstance(数据 , 类型)     bool值，判定数据是否是指定的类型，是为True，否为False
### 字符串定义
单引号(‘Python’)、双引号("Python")、三引号("""Python""")
单引号与双引号是等效的，三引号用于多行字符串等场景
常见转义字符：\\'（单引号）、 \\"（双引号）、 \n（换行符）、\t（制表符）
### 字符串拼接:
- 方式一：+
	只能拼接字符串，其他类型需要转换为字符串：str(...)
- 方式二：%
	语法："%s...%s" %(变量1,变量2) 
- 方式三：f
	语法：f"内容{变量/表达式}”
